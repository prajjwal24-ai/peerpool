# 🚀 PeerPool

**PeerPool** is a full-stack, real-time collaboration and group messaging platform designed for peers to connect, chat, and share study materials seamlessly.

---

## ✨ Features

* **User Authentication:** Secure register & login system with JWT tokens and bcrypt hashing.
* **Real-time Group Chat:** Low-latency live messaging powered by WebSockets (`Socket.io`).
* **File & Media Sharing:** Upload, preview, and download documents (PDFs, images, notes) directly in groups.
* **Live Interactions:** Real-time typing indicators and active status.
* **Responsive Dark UI:** Sleek glassmorphism interface styled with Tailwind CSS.

---

## 🛠️ Tech Stack

* **Frontend:** React (Vite), Tailwind CSS, Axios, Socket.io-client
* **Backend:** Node.js, Express.js, MongoDB, Mongoose, Socket.io, JWT, Bcrypt
* **Deployment:** Vercel (Frontend), Render (Backend)
